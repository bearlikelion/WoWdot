Install

  1. Copy the zip's files into your own 1.12.1 client folder, next to its Data folder.
  2. Run WoWGD.exe or WoWGD.x86_64.
  3. Enter your server's realmlist and log in.

If the realm refuses the login, the server needs StrictVersionCheck = 0 in realmd.conf: that check wants a hash of the stock game executable, which WoWGD does not ship.

WrathGD

Wrath of the Lich King, 3.3.5a (12340) · AzerothCore · In development

The client runs: it logs in, makes a character and walks around Shadowglen. One wowdot build and one folder of GDScript serve both clients; a project setting switches the expansion.

Done so far

  • Login. SRP6 against the authserver, the realm list, the header cipher and the WotLK auth session.
  • Characters. The character list, creating and deleting.
  • World. Entering a WotLK map, with the player's stats read in the WotLK layout.
  • Movement. Walking is sent, the server keeps the position across a relog, and a GM teleport lands.
  • Large packets. The world socket takes the longer header AzerothCore uses above 32 KB.
  • Chat. Lines go out and come back in the WotLK layout.
  • Models. M2 version 264, whose geometry lives in the .skin file beside the model.
  • Terrain. Azeroth and Northrend tiles, with their water.
  • The screens. The login screen, the character list and the create screen, shared with WoWGD.

Next

  • The data the HUD and tooltips read: update fields and Spell columns.
  • Animations, which version 264 moved into .anim files, hundreds per model.
  • The packets still parsed in the 1.12 layout.
  • The 3.3.5a interface, whose FrameXML differs from 1.12's.

The wowdot extension

One C++ GDExtension under both clients

wowdot opens your MPQ archives, decodes the DBC tables, BLP textures, M2 and WMO models and ADT terrain, and speaks the game's network protocol. GDScript builds the interface, the world and combat on top of it.

  • WowArchive
  • WowDBC
  • WowTexture
  • WowLoader
  • WowStreamer
  • WowSession
  • WowCoords

Your data, your install

WoWdot ships no Blizzard code, archives or extracted assets.

The clients read your MPQ archives and talk to whatever server you point them at.

Open source, but later

WoWdot will be MIT licensed.

The source is not published yet; builds come first while the client is still changing quickly. Every release zip carries the LICENSE and NOTICE.md the source will ship under.

About

Made by Mark Arneman (bearlikelion)

Hi! I'm Mark and I make games.

I wanted to explore the possibilities of creating my own MMORPG, by diving deeper into the Godot game engine, and to understand how a game like World of Warcraft works under the hood.

This is an educational project, built for its own sake rather than as a product.

Thanks to

  • WoWee, whose MIT-licensed auth, packet parsing and file format loaders WoWdot is built on.
  • wowdev.wiki, for documenting the client's file formats and protocol so carefully.
  • benilla, a from-scratch 1.12.1 client in Rust and Bevy, for showing how far one can go.
