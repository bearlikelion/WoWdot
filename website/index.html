Your data, your install

WoWdot ships no Blizzard code, archives or extracted assets.

The clients read the MPQ archives of a game install you already own, and talk to a server you point them at.

Build from source

You need Godot 4.7, SCons and a C++20 compiler; every library is a submodule.

git clone --recursive {{REPO_URL}} WoWdot
cd WoWdot/extension
scons target=template_debug

Open clients/wowgd in Godot, set wowgd/client_data_dir to your client's Data folder, and run.
