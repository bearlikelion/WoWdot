Your data, your install

WoWdot ships no Blizzard code, archives or extracted assets.

The clients read the MPQ archives of a game install you already own, and talk to a server you point them at.

Download and play

Grab the Windows or Linux build, or browse every release.

  1. Copy the files from the zip into your own 1.12.1 client folder, next to its Data folder.
  2. Run WoWGD.exe or WoWGD.x86_64.
  3. Enter the realmlist of the server you play on and log in.

Nothing else to install on either platform.
