WoWGD

A Godot client for World of Warcraft 1.12.1 (build 5875), playing on vMaNGOS servers.

Install
1. You need a World of Warcraft 1.12.1 (build 5875) client folder that you own.
2. Copy the files from this zip into that folder, next to the existing Data folder.
3. Run WoWGD.exe (Windows) or WoWGD.x86_64 (Linux, may need: chmod +x WoWGD.x86_64).
4. On the login screen, enter the realmlist address of the server you play on.
5. Log in with an account on that server.

No extra libraries are needed on either platform.
WoWGD ships no Blizzard code, archives or extracted assets; it reads the install you already have.

See NOTICE.md for the third-party components included in this build.
